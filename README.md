# TypingAid-Customize
1. Use top 30000 words from 'Wordlist 100000 frequency weighted (Google Books)'.
2. Skip word suggestions while the Chinese IME is in Chinese (native) mode.
3. Space: accept the highlighted word (first by default), then type a space. If the typed word already matches a candidate, keep it as typed.
4. F2: toggle TypingAid on/off
